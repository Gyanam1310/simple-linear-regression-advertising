# Simple Linear Regression on Advertising Data

Simple Linear Regression (SLR) applied to the Advertising dataset using the
`statsmodels` library to study the relationship between TV advertising spend
and sales.

Dataset  
Advertising dataset  
~200 observations  
Predictor: TV advertising spend  
Target: Sales  

Methodology  
Data preprocessing  
Train–test split  
Intercept added explicitly  
Model trained using Ordinary Least Squares (OLS)  
Predictions and residual analysis  

Model  
Sales = β₀ + β₁ × TV + ε  

Evaluation  
R² score ≈ 0.6 indicating moderate explanatory power  
RMSE used to measure average prediction error  
Residual diagnostics suggest assumptions are reasonably satisfied  

Tools Used  
Python  
pandas  
numpy  
matplotlib  
seaborn  
statsmodels  

Status  
Completed
